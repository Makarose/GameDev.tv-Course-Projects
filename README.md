# GameDev.tv Course Projects

A collection of Godot tutorial projects used to learn game development fundamentals and Godot's engine.

## About

These are practice projects built while following along with GameDev.tv courses. 
Basic functionality works, but expect glitches and unfinished features.
Each folder represents a course. Courses with multiple projects are nested within their course folder.

## Projects

- **Complete Godot 2D: Code Your Own 2D Games In Godot 4**
      * **Speedy Saucer** — Project #1
      * **Alien Attack** — Project #2
      * **Martian Mike** — Project #3

- **Complete Godot 3D: Code Your Own 3D Games In Godot 4**
      - **Project Boost** — Project #1
      - **Barbarian Blast** — Project #2
      - **Robo Rampage** — Project #3

- **Godot 4: Build a 2D Action-Adventure Game**

- **Godot 4: Create and Master Custom Plugins**

Built in **Godot 4** (GDScript).
